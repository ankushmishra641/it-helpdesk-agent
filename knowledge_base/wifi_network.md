# Wi-Fi & Network Guide

## Office networks
- **Company-Secure**: employees (WPA2-Enterprise, corporate credentials)
- **Company-Guest**: visitors (captive portal, internet only)
- **Company-IoT**: approved devices only

## Connect to Company-Secure
1. Select `Company-Secure`.
2. Username: corporate email.
3. Password: corporate password.
4. Accept the certificate if prompted.

## Troubleshooting
### Connected with no internet
- Forget network and reconnect.
- Toggle airplane mode.
- Check proxy settings are set to Automatic.
- Try ethernet if docking station available.

### Authentication failed
- Confirm password is not expired.
- Verify device date/time is correct.
- Forget network, reboot, reconnect.

### Slow network
- Move closer to access point.
- Avoid guest network for work apps.
- Run speed test and attach result to ticket if below 20 Mbps consistently.
