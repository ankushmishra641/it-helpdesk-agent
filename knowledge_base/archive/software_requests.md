# Software Request & Installation Process

## Approved software
Employees may install apps listed in the Software Catalog via Company Portal / Intune.

## Requesting new software
1. Open ServiceNow / IT portal → Software Request.
2. Provide business justification and manager name.
3. Security reviews unapproved vendors (2–5 business days).
4. After approval, package is pushed to your device.

## Common installs
- **Microsoft 365 / Teams**: preinstalled; repair from Company Portal.
- **VPN client**: IT portal → Tools → GlobalProtect.
- **IDE / developer tools**: request via Software Request with project code.

## Blocked installs
Do not sideload `.exe` from the internet. Shadow IT installs may be quarantined by endpoint protection.
If install is blocked, create a ticket under category Software with the blocked app name and error text.
