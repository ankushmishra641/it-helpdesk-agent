# Common Troubleshooting FAQ

## Email not syncing
- Check internet and VPN if remote.
- Remove/re-add Outlook profile only if guided by IT.
- Confirm mailbox not full.
- If outage suspected, check System Status for Email.

## Printer not found
- Connect to Company-Secure (not Guest).
- Install printer from `\\printserver\queue`.
- Restart Print Spooler service.
- Create ticket under Hardware if queue missing.

## Laptop running slow
- Restart device.
- Check disk usage and close heavy apps.
- Run Company Portal device sync.
- If CPU stuck high by unknown process, escalate Security.

## MFA prompt not arriving
- Open authenticator app and sync time.
- Request SMS backup code from identity portal.
- If phone changed, create Priority High Identity ticket.
