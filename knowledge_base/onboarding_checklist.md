# New Employee IT Onboarding Checklist

## Day 0–1
- Activate account using welcome email link.
- Set password and enroll MFA.
- Sign into laptop with corporate credentials.
- Connect to Company-Secure Wi-Fi.
- Install/launch Outlook, Teams, and Company Portal.

## Day 1–3
- Connect VPN once from home to verify remote access.
- Confirm access to email, calendar, shared drives.
- Complete security awareness module.
- Request additional software through Software Request if needed.

## Common first-week issues
- MFA not enrolled → cannot access email/VPN.
- Wrong Wi-Fi (Guest) → no internal app access.
- Password not synced → wait 5 minutes after reset.
